# MDPro3 决斗 · SillyTavern 扩展

在酒馆里运行的游戏王决斗插件，当前版本 **0.1.14**。提供原版 3D 场地、卡组编辑、浏览器决斗内核、二十二种 WindBot 对手和结算战报。无需酒馆助手、服务端插件、Python 或 .NET 服务。

## 通过链接安装

在 SillyTavern 的“扩展”页面点击“安装扩展”，粘贴下面的仓库地址并安装：

```text
https://github.com/kuroneko0514/st-ygo
```

安装完成后刷新酒馆，在扩展设置中找到 **MDPro3 决斗**，点击“打开决斗”。本仓库根目录直接提供 `manifest.json` 和编译后的运行文件，不需要下载源码、解压或自行构建。

如果已经手动安装过 `mdpro3-duel`，先结束当前决斗，移除旧的手动安装目录，再通过链接安装。本仓库会安装为 `st-ygo`；同时启用两个副本会产生重复界面。新旧安装沿用相同的设置和浏览器资源缓存，无需清空站点数据。

## 运行要求

- SillyTavern **1.18.0 或更新版本**。
- 支持 WebGL2、WebAssembly、Worker、CacheStorage 的现代浏览器。
- 通过 HTTPS 或本机 `localhost` 打开酒馆。
- 首次安装需要下载本仓库的运行文件；首次进入游戏还会按需准备本局资源。访问 GitHub 和资源服务所需的网络环境由玩家自行配置。

## 开始与结束决斗

1. 在“决斗准备”中选择卡组、WindBot 对手，以及双方的场地、墓地套件、桌宠、伴侣台、卡背和现有演出选项。
2. 等待所选外观加载完成，再点击“开始决斗”。插件会读取并校验通用资源、双方卡面和专属演出；准备失败可重试，准备期间可取消。
3. “收起”或 Esc 保留当前游戏和音频，“继续决斗”返回同一局。“结束并关闭”释放游戏、音频和 Worker；再次打开会创建新游戏。当前对局没有自动存档，刷新或关闭酒馆会丢失本局。

结算战报可在游戏内查看和复制。此独立扩展的直接写入酒馆聊天功能仍需后续适配，不会自动调用聊天模型。

编辑卡组时，在“决斗准备”中点击“打开卡组编辑器”。编辑并保存后返回，点击“使用卡组编辑器当前卡组”将它用于开局。闪卡、碎闪、金碎和千年闪会在对应卡图与材质加载完成后显示。

## 本地缓存与资源

完整媒体仍使用固定版本的资源服务，打开酒馆不会下载整套素材：

```text
https://assets.cloudxu.de5.net/releases/w14-graves-e8ad35a1baf58f7a2ddebf5f/release.json
```

已经下载并通过 SHA-256 校验的资源会保存在浏览器本地，后续优先复用；固定版本清单也优先读取本地。程序不再按旧的 512MiB／4096 项上限自动淘汰资源。缺少或校验损坏的资源才重新下载；浏览器清理站点数据、存储空间不足或隐私模式可能影响缓存保留。

扩展设置支持更换兼容的资源清单地址，保存后在结束并重新打开游戏时生效。HTTPS 酒馆不能加载 HTTP 资源。不要填写任何 Cloudflare 令牌、S3 密钥或含账号密码的地址。

## 更新与卸载

通过链接安装后，可在酒馆扩展管理页面检查并执行更新。更新前先结束当前对局，完成后刷新酒馆。版本名可能保持不变，运行模块和游戏入口使用构建指纹区分更新；已有资源缓存会继续复用。自动更新默认关闭。

停用或卸载前先结束当前对局。卸载本扩展不会删除聊天、角色和其他扩展的数据；资源缓存可在浏览器的站点存储工具中管理。

## 当前版本

0.1.14 在决斗准备中增加可直接使用的卡组编辑器入口，修复闪卡、碎闪、金碎和千年闪的“卡面效果不可用”问题，包括重新打开时卡图尚未载入的情况。保留原版材质和光效算法。35 项相关回归、四种卡型的 16 种光效组合，以及 Windows 酒馆内已保存金碎设置的实际显示已通过验证；不代表所有卡片、手机硬件或与 Unity 逐像素一致的验收。

0.1.13 在提交桌宠外观前准备全部高级形态与变身特效，并按外观生命周期保留、释放预热程序；交互界面避免深度代理和遍历整份对局历史，保留原选卡生命周期与动画。性能记录可导出运行中新增程序的材质身份。手机真机性能仍待验收。

0.1.12 将兼容布局的桌宠蒙皮移至 WebGL2 骨骼纹理路径，保留原权重、动画与精确阴影边界；加载、着色器准备及有序消息处理使用协作时间预算。手机实际性能以真机验收为准。

0.1.10 优化决斗历史关系与卡片记录的重复计算，为消息播放增加每帧处理预算，去掉桌宠重复更新，缓存未变动的精确阴影边界，并补齐卡片特效与牌堆的着色器预热。保留原有动画、画质、规则及 WindBot 策略。

0.1.9 加入原版全部 78 套墓地与除外外观（156 个近侧／远侧资源），双方可独立选择，使用原版名称。包含数量分级、进出场、高亮与原始动画；新增资源按清单从 R2 加载。保留 0.1.8 的宽屏特写黑边和桌宠攻击时机修复。

包含开局外观与卡背选择、桌宠贴图方向、闪卡显示、局内加速、公开卡返回里侧牌堆时的可见卡面，以及融合特写中心十字细线修正。融合细线已用青眼白龙和鲁莎卡人鱼的浏览器实际绘制对照验证。

Windows 酒馆已有覆盖安装及部分对局验证；长局出牌、连锁和召唤时的卡顿仍在排查，手机兼容性与持续帧率尚未完成真机验收。
